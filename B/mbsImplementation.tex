\section{Complete Documentation Build}
From B on macOS/Linux:
\begin{verbatim}
make -f mbsMakefileMacLinux pdf
\end{verbatim}
This executes pdflatex, BibTeX, makeglossaries, makeindex, and two more pdflatex passes. No active includeonly filter is permitted for final checks. The equivalent inherited PowerShell build is:
\begin{verbatim}
.\mbsMakefilePowerShell.ps1 -Action pdf
\end{verbatim}
The PowerShell path builds documentation; it does not add Windows to the application scope and has not been executed in this macOS review. Toolchain and review evidence belong in \ChapterRef{InstantiationReview} and \ChapterRef{TestEvidence}. A PDF build verifies document processing, not application conformance.
