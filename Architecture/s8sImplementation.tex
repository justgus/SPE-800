\section{Application Baseline}
The control-app processing core on macOS, Windows 11, and iOS and the previously scoped embedded software use C++ (\RequirementRef{REQ-C-101}, \RequirementRef{REQ-C-102}; rationale in \ArchitectureRef{ARC-101}). The iOS UI uses SwiftUI (\RequirementRef{REQ-C-104}). The SwiftUI-to-C++ interface, data ownership, concurrency and UI lifecycle integration require design and verification. No language-interoperation mechanism, C++/Swift version, compiler, SDK version, RTOS, desktop UI toolkit, library, application build command, or implementation version is selected. See \hyperref[Question:Q-106]{Q-106} and the unresolved embedded allocation in \hyperref[Question:Q-116]{Q-116}. This stage contains no application implementation or executed product tests.
